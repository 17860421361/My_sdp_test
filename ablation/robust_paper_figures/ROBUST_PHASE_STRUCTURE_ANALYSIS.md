# 3）robust校准中的相位结构破坏

Table X汇总了Widar和Gait上四种相位校准方法的匹配分类结果。Widar的320种预处理组合已全部完成；在固定去噪、异常值处理、归一化和插值方式形成的80组匹配配置中，linear、polynomial、STC和robust的平均准确率分别为69.97%、69.37%、69.59%和59.48%，robust在全部80组中均取得最低准确率，相对其余三种方法的平均值下降10.16个百分点。截至本次统计，Gait已完成317种组合。为避免缺失组合造成比较偏差，仅统计同时包含四种校准方法的77组配置；四种方法的平均准确率分别为92.83%、90.76%、92.90%和46.38%，robust相对其余三种方法的平均值下降45.78个百分点，并在全部77组中排名最低。验证集上也得到一致结果。因此，robust的退化并非由某一种去噪、异常值处理、归一化或插值方法单独触发，而是稳定地来源于校准阶段。

Fig. X(a)给出了robust的具体处理流程。对于每根接收天线，该方法首先分别沿时间轴展开各子载波的相位，并在每一帧减去跨子载波的中位相位；随后，利用前50帧为每个子载波独立估计Theil–Sen时间斜率 \(\hat{\beta}_{f,a}\)，并从整个序列中减去 \(t\hat{\beta}_{f,a}\)。其中，减去公共相位对同一天线上的所有子载波施加相同修正，不会改变它们之间的相位差；真正改变频率维结构的是后续的独立斜率校正。对于同一天线上的两个子载波 \(f\) 和 \(g\)，处理后的相位差满足

\[
\Delta\phi'_{f,g}(t)=\Delta\phi_{f,g}(t)-t\left(\hat{\beta}_{f,a}-\hat{\beta}_{g,a}\right).
\]

只要两个独立估计的斜率存在差异，额外相对旋转便会随时间累积。由于子载波的时间趋势可能包含人体运动、Doppler响应或相位展开分支带来的变化，将其统一视为硬件误差并分别删除，不仅可能移除任务相关信息，还会重写子载波之间原有的相对相位关系。

Gait的受控组件消融进一步给出了分类层面的根因证据。如Fig. X(b)所示，在固定数据划分、分类模型、随机种子及其余预处理步骤后，不校准和linear校准的准确率分别为95.83%和95.87%，而仅执行独立时间去趋势时，准确率降至70.68%，相对不校准下降25.15个百分点；完整robust的准确率进一步降至67.32%。当仅将每个子载波的独立斜率改为每天线共享斜率时，即先估计同一天线内各子载波的斜率，再取其中位数作为该天线的共同斜率，准确率恢复至93.59%，较原始robust提高26.27个百分点，恢复了其相对linear性能缺口的92.03%。共享斜率仍可消除天线级的共同时间漂移，但由于所有子载波减去相同趋势，其相对相位保持不变。独立去趋势单独造成显著下降，而共享斜率又在仅改变这一因素后恢复大部分性能，二者共同将根因锁定为子载波之间彼此独立的时间斜率校正。

Fig. Y进一步给出了Widar和Gait各64个诊断样本上的信号级证据。在每个样本的最后四分之一帧内，仅去除公共相位时，Widar和Gait相邻子载波的包裹相位差绝对值均值分别为0.812 rad和0.820 rad；单独执行独立时间去趋势后，该指标升至1.439 rad和1.548 rad，与完整robust的1.444 rad和1.552 rad几乎一致。相对于仅去除公共相位的结果，独立去趋势使42.47%的Widar相邻子载波对和49.36%的Gait相邻子载波对产生超过90°的附加旋转；完整robust对应比例为41.85%和48.62%。采用每天线共享斜率后，相位差绝对值均值恢复为0.812 rad和0.820 rad，超过90°的比例降至0%和0.13%。因此，独立时间去趋势几乎能够单独复现完整robust造成的相位破坏，而共享斜率能够保持原有的频率维相位结构。该跨数据集现象与Widar主实验中的系统性下降一致；但由于Widar尚无与Gait同协议的全量分类组件消融，现阶段不能声称共享斜率已经在Widar分类任务上恢复准确率。

其余因素仅构成次要影响或放大机制。Gait中，仅去除公共相位使准确率由95.83%降至90.29%，下降5.54个百分点，说明公共相位可能携带部分判别信息，但其影响明显小于独立时间去趋势。前50帧平均仅占Widar和Gait原始序列的2.98%和1.86%，将由此估计的斜率作用至模型时间范围末端分别形成29.28倍和30.59倍的外推，因而可能放大斜率误差；然而，将50个拟合点均匀分布到模型可见时间范围后，准确率仅由67.32%升至67.83%，提高0.51个百分点且差异不显著（\(p=0.513\)），而限制校正量在第50帧后继续增长反而使准确率降至61.26%。这表明短窗口和长期外推并不是分类退化的主要原因。min-max归一化及复数插值也会放大已受损相位的影响，但在z-score与nearest组合下，robust相对linear在Widar和Gait上仍分别下降8.90和25.20个百分点，说明这些后续步骤同样不是产生退化的必要条件。综上，robust性能下降的主要根因是独立时间斜率校正破坏了跨子载波相对相位；公共相位移除以及后续预处理交互只解释较小的附加损失，前50帧拟合与长期外推则属于潜在放大因素，而非根因。

## 概念

- **基线**是静态环境、设备增益和很慢漂移形成的信号底座。Bandpass 不只去基线，还同时去掉 50 Hz 以上部分，因此`raw−Bandpass` 不能全部叫基线。
- **正/负**表示 Bandpass 零中心的两侧；它不等于上升/下降。
- **上升/下降**看相邻帧差值：`x[t]−x[t−1]>0` 才是上升，小于 0 才是下降。
